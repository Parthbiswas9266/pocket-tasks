# PocketTasks

A simple, mobile-friendly to-do list web app built with HTML, CSS, and vanilla JavaScript.

This is a beginner frontend project created to practise JavaScript fundamentals while building a useful, interactive application.

## Features

- Add up to 10 tasks
- Mark tasks as completed or pending
- Edit and delete individual tasks
- Automatically display pending tasks first
- Save tasks using browser localStorage
- Light and dark themes
- Reset all tasks with confirmation
- Responsive layout for mobile and desktop screens

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Start adding tasks.

No backend, database, or installation of dependencies is required.

## How Data Is Stored

PocketTasks uses the browser's `localStorage` to save tasks and the selected theme.

Data stays in the current browser on the current device. It is not synchronized between devices, and clearing the browser's site data may remove saved tasks.
